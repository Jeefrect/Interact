# Interact Mod CarX

Interact is a CarX Drift Racing Online mod that adds interactive animations to custom Kino objects and CarParts. Players can click doors, hoods, trunks, mirrors, fans, lights, and other vehicle objects to open, close, start, or stop animations.

Full synchronization support between players, provided they have the same mods installed.

### Features

* **Open / Close / Loop** animation support.
* **SpeedActive** animations controlled automatically by vehicle speed.
* **Multiplayer synchronization** between players.
* **Custom key binds** for individual interactions (Hold CTRL + LBM).
* **Custom key binds** for start all animations at once (F8 by default).
* **English, Russian, and Japanese** language support.

For more information check the [Interact Animation Guide](https://github.com/Jeefrect/Interact/blob/main/docs/how-to-make.md)

> [!NOTE]
> Download and install [KSL](https://github.com/trbflxr/ksl) before installing the mod.
